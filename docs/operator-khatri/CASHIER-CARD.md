# CASHIER CARD — BINGOO Online / BINGOO Offline (Roman Urdu neeche)

## Which shortcut, when / Kaun sa shortcut, kab

| situation | open | login |
|---|---|---|
| normal day, internet working / aam din | **BINGOO Online** (desktop) | your usual Cloud login / aam login |
| the manager says "Offline mode is ON" / manager kahe "Offline ON hai" | **BINGOO Offline** (desktop) | employee code + **Edge PIN** |
| the manager says "we are back Online" / manager kahe "wapas Online" | close Offline, open **BINGOO Online**, open a NEW shift | your usual Cloud login |

You switch by hand. The screen does not move you by itself.
Aap khud shortcut badalte hain. Screen khud nahi badalti.

## What the badge at the bottom of BINGOO Offline says / BINGOO Offline ke neeche badge

| badge | meaning / matlab | what you do / aap kya karein |
|---|---|---|
| **STANDBY · CLOUD AUTHORITY** | Offline mode is NOT on — sales go on BINGOO Online / Offline ON nahi — sale BINGOO Online par | close this, open BINGOO Online / isay band karein, BINGOO Online kholein |
| **LOCAL MODE ACTIVE** (green message "Local Mode is active") | Offline mode is ON — sell here / Offline ON — yahin bechein | open shift, sell, print as usual / shift kholein, bechein |

## If a sale is refused / Agar sale inkaar ho

- Message **"This Branch Server is in STANDBY — the Online (Cloud) POS is the active writer"**: you are on BINGOO Offline but Offline
  mode is not on. Your cart is kept on this screen. Tell the manager; sell on BINGOO Online.
  Ye message aaye to aap BINGOO Offline par hain lekin Offline ON nahi. Cart isi screen par mehfooz hai. Manager ko batayein; BINGOO
  Online par bechein.
- **"Permission denied"** on login: your account is not enrolled on the Branch Server — ask the manager, use BINGOO Online.
  Login par "Permission denied": aap ka account Branch Server par enrolled nahi — manager se kahein, BINGOO Online istemal karein.
- A payment type is not offered on Offline (card / online payment): Offline takes **cash** only. Tell the customer; the manager decides.
  Offline par card / online payment nahi hoti: sirf **cash**. Customer ko batayein; manager faisla karega.
- Receipt did not print: open **Recent Prints** (printer icon, bottom right) → **Retry** once. Still nothing → tell the manager.
  Receipt nahi nikli: **Recent Prints** (printer icon) → **Retry** aik baar. Phir bhi nahi → manager.

## Never / Kabhi nahi

- Never open BINGOO Offline "just to try" on a normal day. / Aam din "try" ke liye BINGOO Offline na kholein.
- Never keep selling on Offline after the manager said "back Online". / Manager ke "wapas Online" ke baad Offline par na bechein.
- Never give your Edge PIN to anyone. / Edge PIN kisi ko na dein.
