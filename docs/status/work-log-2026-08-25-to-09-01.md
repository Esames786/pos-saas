## Discipline the week established

1. **A guard must run the real path.** A test that rebuilds the query instead of calling the controller proves nothing. `PosScreenRendersHttpMySqlTest` exists because 480 green tests did not stop a 25-minute outage.
2. **Compile every Blade before it ships.** `voided@endif` cost the Close Branch screen.
3. **Never truncate migration-owned permission tables in a test.**
4. **For a report change: snapshot live prod before and after, and diff.** The deal-identity deploy was proven by a byte-identical match to a read-only prediction — outside the ITEM rows, not one line changed.
5. **Prove the guard bites** — reintroduce the bug and watch the test go red.
6. **Revoke permissions by deleting specific `role_has_permissions` rows.** Never `syncPermissions`. Then `system:clear-tenant-permission-cache`.
