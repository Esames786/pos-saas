## 2. OWNER_REVIEW_REQUIRED enforced at plan / build validation (item 5) — fail closed

Design (code in `EdgeTenantMigrationManifest`, consumers `EdgeLocalSchemaUpgrader`, `EdgeLocalDbInitCommand`,
`EdgeArtifactBuilder`, `EdgeUpdateInstaller`, `EdgeLocalSchemaUpgradeCommand`; package audit via `artifactProblems`):

- Every shipped (non-CLOUD_ONLY) `OWNER_REVIEW_REQUIRED` entry MUST carry **`OWNER_APPROVAL`**, explicit and
  migration-specific. Valid values: `release:<x.y.z>-edge …` (the Edge release that already executed it on every
  appliance), `owner-decision:<YYYY-MM-DD> …` (the owner's dated decision), or `PENDING …`. Anything else (a bare
  `true`, free text, a non-ISO date, an approval on a non-review entry, any approval on a CLOUD_ONLY entry) is a manifest
  validation error — the manifest does not load.
- `PENDING` ⇒ plan decision **`ABORT_OWNER_APPROVAL_PENDING`** ⇒ verdict `RELEASE_BLOCKER`. `edge:local:schema-upgrade`
  refuses with `SCHEMA_UPGRADE_OWNER_APPROVAL_PENDING` before touching the database, `edge:local:db-init` with
  `SCHEMA_INIT_OWNER_APPROVAL_PENDING`, the artifact builder with `ARTIFACT_OWNER_APPROVAL_PENDING_TENANT_MIGRATION`
  (no artifact is produced), the update installer with `UPDATE_MIGRATION_PLAN_BLOCKED` (audit row records the plan and
  `blocker_reasons`). The decision is part of the hashed plan, so an approval changes the plan hash.
- Plan document gains `substitute` and `blocker_reasons`; plan entries gain `owner_approval` and `edge_substitute`
  (`edge-migration-plan-v1` keeps its hash tuples; the dry-run JSON is still recomputable).

  review entries carry none (never executed), R-1 and purchase_bills `owner-decision:2026-11-16 …`, order_note `PENDING …`.
- Tests: `EdgeTenantMigrationManifestTest` (real file: every shipped review entry has an approval, the 16 Nov decisions
  are in effect, the real tree is buildable exactly when nothing is pending; synthetic: pending blocks / approval runs /
  substitute runs-as-substitute, loader rejections, builder refusal) and `EdgeTenantMigrationGateMySqlTest` (the REAL
  manifest blocks each pending migration on an appliance before touching the DB and the dry run exits 1; a planted
