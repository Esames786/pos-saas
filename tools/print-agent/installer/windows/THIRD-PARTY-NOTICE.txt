Why it is here
--------------

Bingoo Print Agent turns an A4/A5 document (quotation, kitchen sheet, address
sheet) into a PDF using the browser already installed on the PC, and then has
to hand that PDF to a Windows printer.

Windows has no built-in way to print a PDF from the command line. There is a
"printto" shell verb, but it only exists when a PDF reader registers it, and
neither Microsoft Edge nor Google Chrome does. On a clean Windows machine that
last resort is therefore simply not available - verified on 10 Oct 2026 against
a real HP Laser MFP, where the whole chain ran correctly right up to that step
and then stopped with "No application is associated with the specified file for
this operation".

SumatraPDF prints a PDF silently to a named printer and needs no installation,
so it is shipped beside the agent. The agent looks for it first, before any
other method.
